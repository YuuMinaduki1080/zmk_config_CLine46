## 19:45 feat/auto-mouse-layer

トラックボール操作で自動的にマウス用レイヤーへ入る仕組み（オートマウスレイヤー）を実装。空きレイヤーだった `layer_5` を `AML` に転用し、`&mkp MB1` / `&mkp MB2` を右手ホームの J / L 位置にのみ配置。`CLine46_R.overlay` の `trackball_listener` に `<&zip_temp_layer 5 300>` を追加し、`require-prior-idle-ms = <200>` と修飾キー中心の `excluded-positions` を設定した。

### 設計判断

- **発動先に既存の MOUSE レイヤー(2) を使わなかった**: overlay に `//<&zip_temp_layer 2 1000>` が用意されていたが、レイヤー2 は左手が F1〜F12・右手が Ctrl+Z/Y/C/V/X/A/F に置き換わる「厚い」レイヤーで、ボール操作直後の打鍵で Ctrl+Z 等が誤発火する。同じ作者の zmk-config-LiNEA40 が「ほぼ全て `&trans` の専用 AML レイヤー」を発動先にしている構成に倣った
- **転用先を `layer_4` ではなく `layer_5` にした**: `layer_4` には `&bt BT_SEL 0`〜`4`（レイヤー3 SCROLL と重複内容）が書かれており上書きすると失われる。`layer_5` は全キー `&trans` の完全な空きレイヤー
- **時間値 300ms / 200ms は LiNEA40 の実測値を踏襲**（ユーザー判断）
- **AML の位置20 に置いた `&mo 3` を撤回して `&trans` に戻した**: AML はレイヤー5 にあり、ZMK ではレイヤー番号が大きい方が優先される。レイヤー2 を手動保持しながらボールを動かすと AML がレイヤー2 を上書きし、位置20 の `&kp UP_ARROW` が潰れる回帰があった。LiNEA40 では AML(4) が MOUSE(5)/SCROLL(6) より下にあるためこの問題が起きず、移植時に非対称が生じていた。位置34 の既存スクロールキーが AML の `&trans` を貫通するため、スクロールへの導線は失われない
- **位置20 を `excluded-positions` からも外した**: `&trans` に戻した時点で「AML の機能キーだから除外する」根拠が消えた。除外を残すと通常のタイピングで `k` を打っても AML が解除されず、直後の `j` が左クリックとして誤発火する。打鍵の安全側に倒した
