### 物理配列の差分をどう埋めたか

CLine46 46キー（6列×2）と LiNEA40 41キー（5列×2＋エンコーダ）で配列が違うため 1:1 コピーは不可。英字ブロックを 1:1 対応させ、段ごとに異なるオフセット（1段目 +1、2段目 +3、3段目 +5）で位置を対応付けた。CLine46 の余剰最外列（左右各1列・計6キー）と右親指の差分はユーザーが個別に決定。

### Y軸反転の実装方法についての注意（将来の事故予防）

`scroller` ノードには Y 反転の候補行が**2つ**、いずれも無効状態で並んでいる。

- `//<&zip_xy_transform INPUT_TRANSFORM_Y_INVERT>` — スクロール変換の**前**に生の Y を反転する
- `//<&zip_scroll_transform INPUT_TRANSFORM_Y_INVERT>` — スクロール変換の**後**にホイール出力を反転する

**この2つは排他で使うこと。** 後日「有効化すれば反転する」と見て両方を有効にすると、反転が2回掛かって打ち消し合い、無反転に戻る。今回は前者を無効化する形で反転を実現しており、チェーン全体に Y 反転は1つも残っていない。

今回は反転の実現手段として「後者を有効化する」案も取れたが、それだと反転が2回掛かって打ち消し合う構成になり、読み手に意図が伝わらないため採らなかった。

## 02:12 fix/pmw3610-rest-sample-time

「しばらく放置した後、トラックボールを動かし始めると最初だけ反応しない」というユーザー報告の原因を PMW3610 の省電力ダウンシフトと特定し、`CLine46_R.conf` で `REST2_SAMPLE_TIME_MS=20` / `REST3_SAMPLE_TIME_MS=100` を明示した。あわせて実在しない Kconfig 名のコメント行を削除し、根拠と出典をコメントに残した。

### 原因

REST2/REST3 のサンプル周期が未指定＝ドライバ既定（100ms / 500ms）だった。無操作が続くと RUN→REST1→REST2→REST3 と落ちていき、REST3 では 500ms に1回しかセンサーを読まないため動かし始めが取りこぼされる。到達までの実効時間は 0.48 + 4.8 + 12.8 = 約18.1秒（各レジスタは ms 値を分解能で切り捨てた値を持つ）。ユーザーの体感「20秒以上放置で発生」と一致した。

### 設計判断

- **REST3 は 20ms まで詰めず 100ms に留めた**。体感で気付かない水準を確保しつつ、NiMH 運用でのアイドル電流の増分を抑えるため。REST2 は小休止の頻度が高いため 20ms
- **ダウンシフト時間を延ばす案は採らなかった**。数分の離席には効くが長時間放置には効かず、症状の根に当たらない
- **`force-awake`（devicetree プロパティ）は採らなかった**。ドライバは `zmk_activity_state_changed` を購読しており、ZMK が非アクティブになると強制覚醒を解除する。`CONFIG_ZMK_IDLE_TIMEOUT=30000` のため30秒で解け、長時間放置の症状には効かない
- **REST2 を 20ms にするとダウンシフトの分解能も変わる**（`128 × REST2_SAMPLE`）。既定17000ms の切り捨て先が 12800ms → 15360ms になり、REST3 到達は約18.1秒 → 約20.6秒へ後ろにずれる。狙いに対しては有利側

### コメントの真偽検証（レビューの主戦場）

初回レビューは REQUEST_CHANGES。指摘は設定値ではなく**追加したコメントの事実主張が検証できない**点に集中した。ドライバ（`badjeff/zmk-pmw3610-driver` の `zmk-0.3`）は west 取得でリポジトリに vendor されておらず、レビュアー側には参照手段が無い。メインループ側で `Kconfig` と `src/pmw3610.c` を実際に開いて既定値・有効範囲（10〜2550ms、分解能10ms）・レジスタ換算（切り捨て除算）・Kconfig 項目の全量を確認し、出典と参照日をコメントに明記して再レビューで APPROVE。

- レビュアーが推定した既定値（REST1 ダウンシフト 9600 / REST2 12800）は実測（5000 / 17000）と食い違っていた。conf にコメントアウトで残っていた `=9600` は既定値ではなく他 fork の README 由来の例示値で、既定と誤読させるため値を削除した
- `CONFIG_PMW3610_FORCE_AWAKE` と `CONFIG_PMW3610_REST3_DOWNSHIFT_TIME_MS` はいずれもこのドライバの Kconfig に存在しない。コメントアウトされていたため無害だったが、実在すると誤読させるので削除して「存在しない」旨を注記に置き換えた
